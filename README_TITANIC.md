# Titanic Data Analysis 🚢

## Project Overview
This project analyzes data from the Titanic disaster using Python.

The goal is to calculate basic statistics and explore passenger survival and age information.

## Dataset
The dataset contains information about 891 Titanic passengers, including:
- Passenger survival status
- Age
- Passenger class
- Sex
- Ticket information

## Analysis
The project calculates:
- Total number of passengers
- Number of survivors
- Number of passengers who did not survive
- Number of passengers under 18
- Survival rate
- Percentage of passengers under 18

## Results
- Total passengers: 891
- Survivors: 342
- Passengers under 18: 113
- Survival rate: 38.38%
- Passengers under 18: 12.68%
